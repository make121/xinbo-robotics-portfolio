OMoE 统一多任务运动控制

在一个策略中控制 Go2 的四足与双足步态。我负责方法设计、策略训练和真机部署，重点解决多任务专家特征重叠，以及仿真特权信息在实机上不可直接获得的问题。

平台Isaac Gym / Unitree Go2部署Jetson Orin · 50 Hz
01A

策略结构与特征解耦

三个专家，共用一套策略

门控按任务组合专家输出。在专家潜在空间加入可微 Gram–Schmidt 正交化，降低异构步态之间的特征冗余。

两阶段状态估计

先预训练特权状态估计器，再联合适应。训练时用 PAS 概率退火逐步把真值替换为估计结果，部署时仅使用机载本体感知。

01B

仿真验证

48.7%MoE 对照

双足分布外仿真。地形类型与训练一致，测试难度更高，每类地形测试 300 次。这里展示的是下楼梯任务成功率。

01C

真机部署与运动表现

策略在 Jetson Orin 上运行，以 50 Hz 控制频率驱动 Go2 底层 PD。实机验证覆盖四足与双足模式切换，以及崎岖地面、斜坡和下楼梯。

02 / 03INTERNSHIP · SIMULATION

PBHC 多技能学习与在线切换

负责技能图、跨技能训练和在线调度。工作从双技能实验扩展到多技能连续切换，在 Isaac Gym 与 PBHC 中完成验证。

角色强化学习算法实习生验证范围人形机器人仿真
  1. 技能图构建

    组织技能状态与过渡数据，以 L1 状态距离匹配候选节点。

  2. 预采样过渡轨迹

    将预采样的切换轨迹纳入训练，改善随机节点切换导致的过渡覆盖不足。

  3. 在线调度

    通过反向多源 Dijkstra 生成跨技能参考轨迹，衔接技能选择与策略执行。
